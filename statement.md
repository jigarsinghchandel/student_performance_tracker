# Student Performance Tracker Using NumPy

## Problem Statement

Managing and evaluating student academic performance manually can be time-consuming and prone to errors. Educational institutions require an efficient system to analyze student marks, calculate averages, assign grades, determine pass/fail status, and identify top-performing students.

The objective of this project is to develop a **Student Performance Tracker** using **Python and NumPy**. The system stores marks of multiple students in different subjects and performs various analytical operations using NumPy arrays.

The application should be capable of:

- Accepting student names and marks.
- Storing data using NumPy arrays.
- Calculating average marks for each student.
- Assigning grades based on performance.
- Determining pass/fail status.
- Identifying the topper of the class.
- Calculating subject-wise averages.
- Generating a rank list based on overall performance.

This project demonstrates the practical use of NumPy for data processing, statistical analysis, and educational performance management while improving programming and analytical skills.

## Objectives

1. To learn and apply NumPy arrays.
2. To perform statistical analysis on student data.
3. To automate grade and result generation.
4. To rank students based on academic performance.
5. To generate meaningful reports from numerical data.

## Expected Outcome

The system will generate a complete performance report containing:

- Student Name
- Subject Marks
- Average Score
- Grade
- Pass/Fail Status
- Class Topper
- Subject-wise Average
- Rank List

## Tools and Technologies

- Python 3
- NumPy Library

## Applications

- School Performance Analysis
- College Student Record Management
- Academic Data Processing
- Learning NumPy Operations through Real-World Data
