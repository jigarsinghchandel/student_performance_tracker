# Student Performance Tracker Using NumPy

## Overview

Student Performance Tracker is a Python-based mini project developed using the NumPy library. The application allows users to store student marks, calculate averages, assign grades, determine pass/fail status, identify the class topper, and generate a rank list.

This project demonstrates the practical use of NumPy arrays and statistical operations in educational data analysis.

---

## Features

- Add student details and marks
- Calculate average marks
- Generate grades automatically
- Determine pass/fail status
- Find the class topper
- Calculate subject-wise averages
- Generate rank list
- Uses only NumPy for data processing

---

## Technologies Used

- Python 3
- NumPy

---

## NumPy Concepts Used

- np.array()
- np.zeros()
- np.mean()
- np.argmax()
- np.argsort()
- np.all()
